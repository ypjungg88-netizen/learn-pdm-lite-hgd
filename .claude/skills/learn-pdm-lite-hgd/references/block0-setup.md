## EXPLAIN

### 1. 오늘 쓰는 데이터

| 용어 | 뜻 |
|---|---|
| 다변수 센서 데이터 | 진동·온도·압력처럼 여러 변수를 동시에 시간 순으로 기록한 데이터. 한 변수만으로는 놓치는 이상을 여러 변수를 함께 보면 잡아낸다 (원본 Day5 본 강의) |
| 진동 (mm/s) | 베어링·회전체 마모, 정렬 불량. 갑작스러운 증가·추세적 상승이 전조 |
| 온도 (℃) | 마찰·과부하·윤활 부족. 서서히 오르는 흐름이 위험 신호 |
| 압력 (bar) | 유압·공압 계통 누출·막힘. 평상 범위 이탈 구간을 표시 |

데이터는 설비 2대 × 25시점 = 50행이다. 2026-09-15 08:00~16:00, 20분 간격.

- 설비A — 프레스 메인모터
- 설비B — 차체 용접로봇 감속기

### 2. 왜 Claude Code에게 준비를 맡기는가

| 기준 | 직접 하기 | 이번 방식 |
|---|---|---|
| 폴더·파일 | 탐색기에서 만들고 복사 | 프롬프트 하나로 Claude Code가 만든다 |
| 데이터 확인 | 엑셀로 열어 눈으로 셈 | 행 수·설비 수·열 이름을 Claude가 세어 보고 |
| 오류 | 검색해서 해결 | "원인과 해결을 한 줄씩 설명하고 고쳐 줘" |

### 3. 케이스 — 가상 데이터라는 표기

이 센서 데이터는 원래 회사 내부 자료라 공개본이 없어 만든 **가상 데이터**다. 실제 기업의 자료가 아니므로, 결과를 공개할 때는 반드시 "실습용 가상 데이터"라고 적는다 (원본 data/README).

## EXECUTE

아래 프롬프트를 붙여 넣으라고 안내한다. `{SKILL_DIR}`는 Phase A 출력 직전에 이 SKILL.md가 있는 폴더의 실제 경로로 바꿔 보여 준다.

```
아래 순서대로 준비해 줘.
1. 내 홈 폴더에 kma-pdm-lite 폴더를 만든다.
2. {SKILL_DIR}/assets/lab/sensor_50_virtual.csv 를
   kma-pdm-lite/data/ 로 복사한다. 원본은 고치지 않는다.
3. python3 가 실행되는지 확인하고, 없으면 설치한다.
4. 복사한 CSV의 행 수, 설비 이름, 열 이름을 세어
   kma-pdm-lite/env_check.txt 에 적는다.
5. 비밀번호나 계정 정보는 묻지 않는다.
```

### 확인할 것 (Phase B)

- `~/kma-pdm-lite/data/sensor_50_virtual.csv`가 있고 데이터 행이 50개다.
- 설비가 2개(설비A 프레스 메인모터, 설비B 차체 용접로봇 감속기)다.
- `~/kma-pdm-lite/env_check.txt`가 있고 python3 버전이 적혀 있다.

막히면 원인을 Claude Code에게 찾게 하는 후속 프롬프트를 준다. 정답은 "정답 보기" 요청이 있을 때만 연다.

```
방금 준비가 안 된 원인을 한 줄로 설명하고, 고친 뒤 env_check.txt 를 다시 만들어 줘
```
